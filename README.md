# TaskManager: A simple and minimalistic task management app

A professional-grade task management application built to demonstrate core backend principles, including user authentication, CRUD operations, and relational database management.

## 🚀 Features
- **Secure Authentication:** Built with Django's built-in auth system (Session-based).
- **CRUD Operations:** Create, Read, Update, and Delete tasks.
- **RESTful Architecture:** Built for scalability and maintenance.
- **Responsive Design:** Clean, template-based UI.

## 🛠 Tech Stack
- **Backend:** Django (Python)
- **Database:** SQLite (Development)
